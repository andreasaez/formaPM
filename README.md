## Step 1- Setup Skills

Set each of the skills as separate md files.

## Step 2 - Create your project
Create the project from the problem-guide-project.md file

## How to use it

**Skills:** `positioning` → `icp-builder` → `feature-comms` → `launch-brief` → `messaging-builder` → `vfd-framework`

**Project instructions:** `problem-guide-project.md` with ICP and positioning placeholders

**Setup order when you're ready to go live:**

1. Install all six skills
2. Paste the updated Problem Guide instructions into the project
3. Run positioning skill → paste output into project
4. Run ICP skill → paste output into project
5. Use the `problem-guide-project.md` to either create a new PRD or upload an existing one
    1. Trigger `vfd-framework` to review and analyze
    2. New task → Use `feature-comms` → `launch-brief` → `messaging-builder`  to generate all assets
    

<aside>
💡 Be sure to always use the same project so it learns from the ongoing context you’re providing it.
